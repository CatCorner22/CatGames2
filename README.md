# KittenPlay (CatGames)

**Gentle, enriching tablet games for kittens** — built for XP-Pen and other touch tablets.

Soft motion · non-scary · high-contrast targets · stylus & paw friendly · short sessions.

## Game series

| Game | What cats do |
|------|----------------|
| **Laser Dot** | Chase a soft glowing “laser” that glides and darts |
| **Flutter** | Bat at a gentle butterfly |
| **Scurry Mouse** | Pounce practice — freezes, then skitters away |
| **Bubble Pond** | Pop soft rising bubbles into sparkles |
| **Yarn Ball** | Roll and bounce a cozy yarn toy |
| **Firefly Garden** | Calm twilight lights for low-stimulation enrichment |
| **Pond Fish** | Watch / dab at colorful swimming fish |
| **Surprise Treats** | Friendly treat icons appear, linger, and fade |

## Settings (tablet-friendly)

- **Energy:** Calm · Playful · Zoomies  
- **Target size:** Small · Medium · Large  
- **Movement:** Auto roam (hands-free) · Follow stylus · Mixed  
- **Soft sounds:** Off by default (optional gentle chimes)  
- Controls auto-hide so kittens focus on the toy, not the UI  

## Install on an XP-Pen / Android tablet

1. Open the live KittenPlay URL in **Chrome** or **Edge** on the tablet.  
2. Menu → **Add to Home screen** / **Install app**.  
3. Launch full-screen from the home icon.  
4. Lay the tablet flat on a non-slip mat; start on **Calm** + **Auto roam** for new kittens.  
5. Keep sessions short (a few minutes); end on a “win,” then offer a real toy or treat.

> Screen play is enrichment — never leave glass where a cat can push it off a high surface. Supervise young kittens.

## Design principles

- No strobing, jump-scares, or loud sounds  
- Smooth, frame-rate independent motion (delta-time)  
- Large hit targets for paws and styli  
- Rest reminders during longer sessions  
- Soft vignette and pastel/dark scenes that stay calm  

Made for curious cats. Play kind.
